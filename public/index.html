A session, start to finish

  1. Provision

    A fresh E2B or Daytona pod spins up for this session only.

  2. Clone

    Your repo, your branch, checked out inside the pod.

  3. Inject

    Secrets land in the pod — never on the wire to the model.

  4. Run

    Pi’s agent loop edits, builds, and tests, streamed to your TUI.

  5. Dispose

    Quit and the pod stops. Disk can persist, so uncommitted work isn’t lost.

Open source, pod-first

CLI, server, and clients live under the pi-pod org. Start with the CLI, then wire the control plane at api.pipod.dev when you need multi-device or team workflows. 

$ git clone https://github.com/pi-pod/pi-pod.git
$ cd pi-pod && npm install && npm run build && npm link
$ cd your-repo && pi-pod
