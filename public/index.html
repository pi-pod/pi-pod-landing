Coding agents, isolated by default

Every pi session in a fresh pod

pi-pod launches a clean provider-managed pod, clones your repo, injects secrets, and runs Pi’s agent loop there — while the real interactive TUI stays on your machine.

Get the CLI Hosted control plane 
git clone https://github.com/pi-pod/pi-pod.git
cd pi-pod && npm install && npm run build && npm link
cd your-repo && pi-pod

Pod boundary

Tools, shell, extensions, model calls, and session files stay inside the pod. Your laptop owns the TUI, host preferences, and the RPC bridge.

Disposable compute

Each run provisions a fresh E2B or Daytona pod. When you quit, the pod stops — disk can persist so uncommitted work isn’t lost.

Hosted path

The control plane at api.pipod.dev backs multi-device and team workflows. This site is the public front door for the product.

Open source, pod-first

CLI, server, and clients live under the pi-pod org. Start with the CLI, then wire the hosted API when you need it.
